    Candidatos a redundantes: el contrato ya lo cubre

    La petición viola una restricción del OpenAPI y el escenario solo verifica estado y código. Schemathesis generó casos negativos contra esa misma restricción (columna "evidencia"). Antes de borrar un escenario, revisa si pertenece al análisis EP/VL (docs/casos-equivalencia-limites.md): ahí se documenta igual, aunque la herramienta lo repita. Lo que Schemathesis no comprueba con estos checks es el código de error exacto (p. ej. PIN_INVALIDO).

    Reglas de negocio: solo las cubre BDD

    La petición cumple el OpenAPI y aun así la API la rechaza. El esquema no expresa la regla, así que Schemathesis solo puede toparse con ella por azar. Columna "Schemathesis": si alguna vez obtuvo ese mismo código.

    Repetidos dentro de BDD

    Ejemplos de un mismo escenario con la misma respuesta y la misma restricción violada. Si son representantes de una misma partición de equivalencia, basta con uno. Si están a los dos lados de un valor límite (p. ej. 2 y 3 caracteres), no sobran.
